
# Free Stata Reader File

Cet outil permet de téléverser un fichier Stata (.dta), de visualiser les données et de les exporter en formats CSV ou Excel.

## Fonctionnalités

- Chargement et affichage des fichiers Stata (.dta).
- Visualisation des données sous forme de tableau interactif.
- Exportation des données en CSV et Excel.
